## Part A — 為什麼參考片「沒有 AI 感」：五大機制

逐幀拆解後，「不像 AI」不是單一原因，而是 **五個機制同時成立**。缺任何一項，AI 感就會回來。

| # | 機制 | 參考片的具體表現 | 為什麼 AI 片會失敗 |
|---|------|----------------|------------------|
| **R1** | **次級動態（Secondary motion）** | 胸部、髮絲、衣料**跟隨身體但延遲一拍**；身體停了，它們還在動 → 慣性感 | AI 常讓全身「剛體同步」移動，衣髮胸與身體同時起停＝塑膠感 |
| **R2** | **微表情連續流動** | 表情**沒有一刻是靜止的**：眼神漂移、眨眼、嘴角微調、下巴微抬，且**彼此不同步** | AI 常用「一個表情維持數秒」或表情整齊切換＝面具感 |
| **R3** | **不對稱（Asymmetry）** | 笑容一邊高、單邊挑眉、頭always 微傾（never 正對）、瀏海不對稱散落 | AI 傾向生成對稱完美臉＝恐怖谷 |
| **R4** | **自然光皮膚質感** | 大面積**窗光柔光**，皮膚有油光/高光但**保留毛孔與膚色不均**；髮絲有透光 | AI 常過度磨皮、膚色均勻、無高光層次＝蠟像感 |
| **R5** | **鏡頭與被攝者的「關係」** | 手持微晃、主角**眼神持續與鏡頭互動**（看/避開/再看回）、像在跟人講話 | AI 片常是「對著空氣表演」，眼神無焦點、機位死板 |

### A.1 參考片實測數據

| 維度 | 觀察 |
|------|------|
| 規格 | 544×960 / 30fps / 9.8s（**解析度不高，卻依然真實** → 證明「真實感 ≠ 解析度」） |
| 打光 | **大面積窗光**（畫面右側落地窗），柔和、方向明確、正面偏側 45° |
| 場景 | 明亮居家客廳/廚房（有景深、有生活雜物：植栽、瓶罐、地毯） |
| 服裝 | 白色平口 crop top + 白短褲 + 黑色薄紗外套（**外套是次級動態的關鍵道具**） |
| 動作 | 半身手勢舞為主，幅度中等，重心小幅上下彈跳（bounce） |
| 取景 | **腰上半身**為主，主體填滿畫面 ~70%（臉夠大、表情看得清） |

> **關鍵洞察：** 這支片解析度只有 544×960，比我們的 1080p 產出**還低**，卻更像真人。
> **證明「真實感」來自表演與物理，不是畫質。** 我們補了解析度，但沒補表演——這就是剩下的差距。

## Part B — 表演設計：兩個 Agent 的分工

> 你提到要用「表演藝術 Agent」與「情緒 Agent」。本 repo 目前**尚無**這兩個 agent
> （`.claude/agents/` 只有 3 個技術類）。以下先定義它們的**職責與產出規格**，
> 作為後續建立 subagent 的規格書；在建立前，可由人 / 通用 agent 依此清單執行。

### B.1 表演藝術 Agent（Performance Director）

**職責：** 決定「身體怎麼演」——動作品質、節奏、物理、鏡頭關係。

產出：**Performance Sheet**（每支影片一份）

| 欄位 | 內容 |
|------|------|
| 動作品質 | 力度（sharp / smooth）、重心、彈跳幅度 |
| 次級動態 | 指定會晃動的元素（髮、外套、耳環、衣擺）與延遲拍數 |
| 呼吸與停頓 | 何處吸氣、何處 freeze、何處鬆下來 |
| 鏡頭關係 | 手持晃動程度、與鏡頭距離、何時「靠近鏡頭」 |
| 段落 | 亮相 → 主歌 → 副歌記憶點 → 收尾（呼應 `05` §C.a） |

### B.2 情緒 Agent（Emotion Director）

**職責：** 決定「臉怎麼演」——情緒曲線、微表情時間軸、眼神走向。

產出：**Emotion Timeline**（逐秒標註）

| 欄位 | 內容 |
|------|------|
| 情緒基調 | 該支影片的主情緒（俏皮 / 自信 / 慵懶 / 挑逗但不低俗） |
| 微表情事件 | 每 1–2 秒一個事件：眨眼 / 挑眉 / 抿嘴 / 歪頭 / 眼神漂移 |
| 眼神腳本 | 看鏡頭 → 移開 → 回望（**與鏡頭建立關係**，R5） |
| 不對稱指令 | 指定單邊笑、單邊挑眉（R3） |
| 情緒轉折點 | 對齊音樂重拍的表情變化 |

## Part C — 表演擬真 SOP（可執行）

### C.1 生成前：素材與 prompt 層

| 項目 | 規格 |
|------|------|
| **取景** | **腰上半身為主**，主體填滿 60–75%（臉要大到看得見微表情——這是表演的前提） |
| **打光** | **大面積自然窗光**優先（柔、方向明確、45° 正側）；避免無方向平光 |
| **服裝** | **必須含一件會飄動的元素**：薄紗外套 / 開襟衫 / 長髮放下 / 耳環（R1 的載體） |
| **場景** | 有生活感雜物與景深的真實空間（植栽、瓶罐、家具），避免空白棚景 |
| **皮膚 prompt** | `natural skin texture, visible pores, subtle skin oil highlights, no heavy retouching`（R4） |
| **不對稱 prompt** | `slight head tilt, asymmetric smile, hair falling naturally over one side`（R3） |

### C.2 生成中：動作驅動層（接 `05` F.6）

- **首選：真人參考驅動**（`motion_control`）——次級動態（R1）與微表情（R2）**最可靠的來源就是真人驅動片**，
  比純文字 prompt 穩定得多。
- 驅動片選擇準則：**選有頭髮/衣物飄動、表情豐富、有鏡頭互動**的真人片段。
- 若用文字驅動，需在 prompt 明確寫入：`hair and clothing sway with inertia, natural breathing motion, continuous subtle facial movement`。

### C.3 生成後：檢核（AI 感偵測）

逐項檢查，**任一項不過就重做**：

- [ ] **R1 次級動態**：暫停在身體停止的瞬間 → 髮/衣**是否仍在動**？（若同步靜止 = 失敗）
- [ ] **R2 微表情**：隨機抽 3 個相隔 1 秒的幀 → 表情**是否都不一樣**？（若相同 = 面具感）
- [ ] **R3 不對稱**：臉是否過度對稱？頭是否始終正對鏡頭？（是 = 失敗）
- [ ] **R4 皮膚**：放大臉部 → 是否有毛孔與高光層次？（全平滑 = 蠟像）
- [ ] **R5 鏡頭關係**：眼神是否**有焦點且與鏡頭互動**？機位是否有生命感的微晃？
- [ ] **手部**：手指數量、形狀正確（AI 最易崩處）

## Part D — 評分 rubric（接 `05` Part D）

在既有「性感 × 青春 × 娛樂 × 優雅」四軸之外，**新增第五軸**：

| 軸 | 1（不及格） | 3（可用） | 5（理想） | 門檻 |
|----|-----------|----------|----------|------|
| **擬真 Realism** | 明顯 AI 感：面具臉、剛體移動、蠟像皮膚 | 大致自然，偶有僵硬 | **看不出是 AI**：物理、表情、皮膚、眼神皆自然 | **≥4** |

> **一票否決（新增）**：擬真軸 ≤2 → 直接重做。
> AI 感是所有努力的天花板——舞跳得再好、畫質再高，一眼看出是 AI 就前功盡棄。

## Part E — 我們現況 vs 本標準（差距）

以已產出的 `sofia_dance_A/B` 對照：

| 機制 | 我們現況 | 差距 | 補法 |
|------|---------|------|------|
| R1 次級動態 | 部分有（甩髮） | 服裝無飄動元素（貼身 crop top + 牛仔褲） | 改穿**薄紗外套 / 開襟衫**，長髮放下 |
| R2 微表情 | 弱——表情變化少 | ★★★ 最大差距 | 選**表情豐富的真人驅動片**；加近景 cut-in |
| R3 不對稱 | 尚可 | — | prompt 加不對稱指令 |
| R4 皮膚 | 偏精修 | ★★ | prompt 加 `visible pores / no heavy retouching` |
| R5 鏡頭關係 | 弱——全身遠景、眼神無互動 | ★★★ | **取景收到腰上半身**、選有鏡頭互動的驅動片 |

> **結論：** 我們已補完「畫質」與「舞步」，**剩下的差距全在表演層**——
> 特別是 **R2 微表情**與 **R5 鏡頭關係**，兩者都靠「**取景收緊 + 選對真人驅動片**」一次解決。

## 附錄：一句話總結

> **真實感不是畫質做出來的，是「物理 + 表情 + 眼神」演出來的。**
> 讓髮與衣**慢半拍**、讓表情**一刻不停且不對稱**、讓皮膚**留下毛孔**、
> 讓眼神**真的在看鏡頭裡的人**——四件事到位，AI 感就消失了。
