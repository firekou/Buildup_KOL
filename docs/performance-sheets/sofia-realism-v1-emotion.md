## 0. 取景前提（必須先成立，否則本時間軸無效）

微表情在寬景裡是看不見的。本片已定腰上半身，但要再鎖死三件事：

| 項目 | 規格 | 為什麼 |
|------|------|--------|
| 臉部佔比 | **臉高 ≥ 畫面高度的 18%**（理想 20–24%）；主體填滿 60–75%（`07` §C.1） | 低於 18% 時眨眼與嘴角微調在手機上完全讀不到 |
| 眼睛位置 | 落在**上三分線附近**，不要讓臉貼到畫面頂 | 眼神是 R5 的載體，不能被裁切 |
| 舞蹈幅度 | 上下彈跳不得讓**頭頂出框或臉縮小超過 15%** | 一旦跳出構圖，時間軸中段的表情全部作廢 |
| 建議加碼 | 在 `0:05.0–0:07.5` 副歌段插一個 **胸上近景 cut-in** | `07` Part E 明確指出「近景 cut-in」是補 R2 最快的手段 |

> ⚠️ **若最終輸出是全身或膝上景，請退回重做取景，不要硬套本時間軸。**
> 舊片 `sofia_dance_A/B` 失敗的根因就是「全身遠景 + 眼神無焦點」（`07` Part E）。

## 1. 情緒基調（Emotional tone）

**主基調：自信的俏皮（confident playfulness）— 帶一點「跟閨蜜炫耀」的親暱感。**

Sofia 的人設是 *"Full flavor, no filter."*、`relatable / warm / bold / chaotic-good`。
她**不是**在對一群陌生粉絲表演，她是在**對鏡頭後面那個具體的人**跳給她看。

| 情緒配比 | 佔比 | 表現 |
|---------|------|------|
| 自信 Confident | 40% | 下巴不縮、眼神敢直視、動作到位不猶豫 |
| 俏皮 Playful | 35% | 半邊笑、挑眉、忍笑、偷瞄 |
| 溫暖 Warm | 15% | 眼周有笑肌參與（真笑），不是只有嘴 |
| 挑逗 Flirtatious | 10% | **僅限「自信 + 眼神」路線**，不做舔唇/咬唇/半闔眼的挑逗 |

### 尺度紅線（`05` Part D：優雅軸 ≤2 一票否決）

| ✅ 要 | ❌ 不要 |
|------|--------|
| 直視鏡頭的自信、忍不住的笑、單邊挑眉的挑釁感 | 咬唇、舔唇、長時間半闔眼（bedroom eyes） |
| 嘴角上揚的暖笑、眼周皺起的真笑 | 張嘴喘息、伸舌、對鏡頭做親吻嘴型 |
| 「我知道我很好看」的玩笑式得意 | 「求你看我」的討好式媚態（違背 character.md「不裝柔弱博同情」） |

> Sofia 的性感來自**她自己覺得好玩**，不是來自對觀眾示好。這是整支片的表演心法。

### 2.1 去同步帳本（Desync Ledger）— 給檢核用

各通道各自的時間點，**任兩個通道的變化間隔 ≥ 0.15s（約 4–5 幀 @30fps）**，唯一例外是 `0:07.5` 的情緒高點：

| 通道 | 事件時間點 |
|------|-----------|
| 眨眼 Blink | `0.6` · `2.2` · `3.1`+`3.35` · `5.4` · `6.9` · `8.0` · `9.7` |
| 眉 Brow | `1.4` · `4.2` · `6.2` · `9.0` |
| 嘴 Mouth | `0.9` · `2.8` · `4.75` · `7.3` · `8.6` · `10.2` · `10.45` |
| 眼球 Eye dart | `1.8` · `3.6` · `5.8` · `7.8` · `9.3` |
| 頭 Head | `2.4` · `4.95` · `7.5` · `10.0` · `10.45` |

> **兩條互斥原則：**
> 1. **不准全同步**——眨眼／挑眉／嘴角同幀變化＝動畫感。
> 2. **也不准全不同步**——完全零共發同樣假。故保留 `0:07.5` 一次共發作為情緒高點。
>
> **最長靜止容忍：0.8s。** 任何連續 0.8s（24 幀）內若五個通道皆無變化 → 判定為 R2 失敗，重做。
> 檢查上表：最大空窗為 `0:10.45`→片尾，其餘皆 < 0.7s。

## 3. 眼神腳本（Eye-line Script）— R5

眼神必須**有具體對象**。以下為她「真的在看什麼」的命名清單，請寫進 prompt 與 driver 挑選標準：

| 代號 | 命名焦點 | 空間位置 |
|------|---------|---------|
| **[LENS]** | 鏡頭玻璃本身 | 正前方 |
| **[PERSON]** | 拿手機的人（設定為閨蜜 Daniela）的**眼睛**，位置比鏡頭高一點、偏後 | 正前方稍上，**焦點越過鏡頭平面** |
| **[WIN]** | 右前方的落地窗（本片光源） | 她的右／畫面左 |
| **[SELF]** | 自己的左肩與垂落的髮絲 | 她的左下／畫面右下 |
| **[OFF]** | 畫面外下方，「想事情」的無焦點漂移（**最多 0.4s**） | 她的左下 |

### 眼神走向（look in → glance away → return，共 3 個循環）

| 時段 | 焦點 | 意圖 |
|------|------|------|
| `0:00.0 – 0:01.7` | **[LENS]** | 開場直視：先建立關係再開始跳 |
| `0:01.8 – 0:02.1` | **[OFF]** | 0.3s 的短漂移（不是放空，是「壞主意冒出來」） |
| `0:02.1 – 0:03.5` | **[PERSON]** | 回望，且是看「人」不是看「鏡頭」——瞳孔聚散略有變化 |
| `0:03.6 – 0:05.7` | **[WIN]** | 全片最長的一次離開（2.1s）。**必須有這一段**，否則「回望」不成立 |
| `0:05.8 – 0:07.7` | **[LENS] → [PERSON]** | 回望並鎖定，副歌進場 |
| `0:07.8 – 0:08.0` | **[SELF]** | 瞄一眼自己的肩／髮，0.25s |
| `0:08.0 – 0:09.2` | **[LENS]** | 回鏡頭，但視線略高於鏡頭中心（看眉毛不看眼睛的錯位感） |
| `0:09.3 – 0:10.5` | **[PERSON]** | 收尾鎖定，**焦點明確落在鏡頭後 30cm**，全片最親密的一次 |

**技術註記（給生成端）：**
- 眼球**不可**只做左右平移；每次移動要有 **微幅過衝 + 回正（overshoot & settle）**，這是 saccade 的真實特徵。
- 眼神移動時，**頭部要晚 2–3 幀才跟上**（眼領頭、頭跟隨），反過來就是機器人。
- 全片瞳孔至少要有一次可見的**聚焦切換**（遠 → 近），發生在 `0:09.3` 的 [LENS]→[PERSON]。

## 4. 不對稱指令（Asymmetry）— R3

| 部位 | 指令 | 貫穿全片 |
|------|------|---------|
| **笑容** | **她的左嘴角（畫面右）永遠高於右嘴角**，落差約 3–5% 臉寬；右嘴角**慢 3–4 幀**才跟上 | ✅ 恆定 |
| **眉毛** | 主挑眉為**左眉**（`0:01.4`）；`0:06.2` 換成右眉，製造變化。**兩眉高度基準本來就差約 2px** | ✅ 恆定基準差 |
| **眼睛** | 她的右眼（畫面左）眼裂略小 2–3%，笑起來時右眼先瞇 | ✅ 恆定 |
| **頭部** | **全片頭部傾角絕不為 0°**，在 **4°–9°** 之間游走，且左右各出現至少兩次（見時間軸 T1–T4） | ✅ 恆定 |
| **臉朝向** | 臉部 yaw 維持 **5°–15° 的 3/4 側向**，只在 `0:07.5` hook 那一拍短暫接近正面（仍保留 4° 傾角） | ✅ 恆定 |
| **頭髮** | 深棕長波浪捲：**多數髮量落在她的右肩（畫面左）前方**，左肩（畫面右）露出鎖骨；有 1–2 綹碎髮垂在**右臉頰前**並隨動作擺動 | ✅ 恆定 |
| **光影** | 45° 窗光從她的右前方（畫面左）來 → **左臉（畫面右）比右臉暗約 1 級**，臉上不對稱陰影是 R3 的免費紅利 | ✅ 恆定 |
| **首飾** | 金飾**不對稱**：她的左耳一只較長的金耳環（會晃 → 同時服務 R1），右耳小耳釘 | ✅ 恆定 |

> **反例（一律重做）：** 正對鏡頭 + 兩邊等高的笑 + 兩眉齊挑 + 頭髮左右對稱分落 = 教科書級恐怖谷。

## 5. 情緒轉折點（對齊重拍）

| 轉折 | 時間 | 音樂位置 | 情緒轉向 | 臉部主事件 |
|------|------|---------|---------|-----------|
| **T0** | `0:00.0` | 入拍 | 「欸你開始拍了喔」——半驚半玩 | 抿嘴忍笑 + 眨眼（`0.6`/`0.9`） |
| **T1** | `0:02.4`（早 0.1s） | 第 2 小節重拍 | 忍笑 → **放開笑** | 頭換邊 + 左嘴角先上揚 |
| **T2** | `0:04.95`（早 0.05s） | 副歌進場 | 玩鬧 → **自信上升** | 下巴上抬 + 慢眨 + 回望鏡頭 |
| **T3** | `0:07.5`（**準點**） | 記憶點 hook | 自信 → **得意的巔峰** | 頭 snap + 眼神直射（唯一共發） |
| **T4** | `0:10.0`（準點） | 收尾重拍 | 巔峰 → **鬆下來的暖笑** | 頭反向傾 + 不對稱大笑 |

> **專業細節：** T1／T2 刻意**搶拍 0.05–0.1s**（真人會預期節拍），T3／T4 準點落。
> 若四個轉折全部「準點」，會產生機械對拍感——這也是 AI 感的一種。

## 7. 真人驅動片（Driver Clip）挑選標準

管線是 motion-driven，**微表情與眼神主要來自驅動片，不是來自文字 prompt**（`07` §C.2）。
選錯驅動片 → 上面整份時間軸不會發生。挑片時按這張表打勾：

### 7.1 必要條件（缺一不可）

| # | 條件 | 怎麼驗 |
|---|------|--------|
| D1 | **臉夠大**：驅動片中臉高 ≥ 畫面高 15%，且**全程不被手/髮/麥克風遮住** | 臉太小 → 臉部關鍵點抓不到，表情不會被轉移 |

| D8 | 長度 ≥ 11s（比目標長 0.5–1s，留對齊餘裕）、30fps、9:16、**單人置中** | 多人/群舞會干擾 motion 抽取 |

### 7.2 加分條件

- 有**眉毛快閃**（brow flash）或單邊挑眉的鏡頭 → 直接餵滿 R3。
- 有**忍笑**（嘴角下壓但眼睛在笑）的瞬間 → 這是最難用 prompt 生出來的表情。
- 頭髮放下 + 有飄動的外套／耳環 → 順便服務 R1（次級動態）。
- 拍攝者與被攝者顯然認識（有互動感、像在對人講話）→ R5 的質感直接繼承。

### 7.3 立即淘汰（Red flags）

| ❌ | 原因 |
|----|------|
| 全身景 / 遠景舞蹈片 | 臉部資訊不足，R2 R5 全滅（這正是舊片失敗主因） |
| 全程同一個笑容不變 | 會把「面具」原封不動轉移到 Sofia 臉上 |
| 戴墨鏡、瀏海遮眼、低頭跳 | 眼神無法轉移，R5 直接歸零 |
| 快速剪接／多機位切換 | motion control 需要單一連續鏡頭 |
| 強烈頻閃／彩色 LED 打光 | 破壞 R4 皮膚質感判讀 |
| 舔唇咬唇等挑逗動作 | 會被轉移，違反 `05` Part D 優雅軸 |

### 7.4 對齊備註

驅動片的表情節奏**不會剛好等於本時間軸**。處理順序建議：
1. 先按 §7.1 選片（表情密度優先於舞步好看程度）。
2. 用驅動片**實際的**眨眼／回望時間點，回頭微調本文件的 T1–T4，**保持「不同步」原則即可**，不必硬對數字。
3. 音樂 tempo-fit 對齊 T3（`0:07.5` hook），其餘轉折自然落位。
