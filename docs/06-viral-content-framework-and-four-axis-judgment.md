# 爆款方法論與四維判準（Viral Framework & Four-Axis Judgment）

**版本：** v1.0
**制定日期：** 2026-08-03
**適用範圍：** `Buildup_KOL/` 所有 KOL 的內容企劃、圖像／影片生成與發片前審核
**性質：** 提煉文件——不新增規則，而是把已散落在 `docs/01`–`05`、`.claude/skills/kol-builder/references/`
與 11 位 KOL `content_style.md` 中的判斷方式，收斂成一套可重複執行的思維框架。

> **這份文件回答兩個問題：**
> 1. **爆款怎麼「找」？**（Part A–C）——不是靈感，是一套「雷達 → 拆解 → 套模板」的流程。
> 2. **做出來的東西怎麼「判」？**（Part D）——娛樂性 / 音樂性 / 真實性 / 動作流暢性四軸評分。
>
> 與 [`05` Part D](05-kol-dance-inhouse-method-and-tuning.md) 的「性感 × 青春 × 娛樂 × 優雅」rubric
> **並行、不衝突**：那份判的是**表達尺度**（會不會低俗），本文件 Part D 判的是**製作品質**
> （好不好看、卡不卡拍、真不真、順不順）。發片前兩份都要跑。

## Part 0 — 三個底層思維（Meta-Mindsets）

整個 repo 的所有做法，往上抽三層只剩三句話。後面所有章節都是這三句的展開。

### 思維一：不模仿作品，只抽「參數組合」

看到一支好片，repo 的標準動作**從來不是「照著做一支」**，而是把它拆成幾個**可以被重新排列組合的軸**。

| 拆解對象 | 抽出的參數軸 | 出處 |
|---------|------------|------|
| liangliang 5 支參考片 | **舞蹈原型 × 打光原型 × 場景原型**（三元組合） | `04` §1–§2 |
| DANZZUP / BABYMONSTER Reels | **記憶點 / 段落 / 服裝 / 場景打光 / 選曲 / 尺度 / 適配 KOL**（七欄配方） | `05` §F.4 |
| 男性參考照 3 張 | **身分錨點 / 造型母題 / 姿態準則 / 場域類型** | `03` |
| 4 個真實參考帳號 | **代表特質 → 融合／轉化方向** | `style-guideline.md` §6 |

> **判斷標準：** 拆完之後，如果這些欄位可以拿去套在**另一位 KOL、另一首歌、另一個場景**上仍然成立，
> 才算拆對了。拆出來只能用在原作身上的東西，是描述，不是方法。

### 思維二：先補地基，再拉感染力

`05` §B.1 的結論是整個 repo 最重要的一句判斷：

> **「我們贏在『跳』，輸在『拍』。」**

舞蹈本身更強，但因為 **低解析度 + 全身遠景 + 平光** 三件事疊在一起，看起來反而不精緻。
所以順序是固定的：**先做「隱形三補」（解析度 / 取景 / 打光），再談創意調優。**

> **推論到所有內容：** 當一個東西「說不出哪裡輸」時，先查**製作基本面**（清晰度、構圖、光），
> 而不是先改創意。基本面的缺陷會偽裝成創意問題。

### 思維三：所有規則都是「AI 生不出來」倒推出來的

`content-production-rules.md` 幾乎每一條都不是美學偏好，而是**生成失敗的止血**：

| 規則 | 真正在防的失敗 |
|------|--------------|
| 不寫逐秒時間軸腳本 | 動作變成一格一格、卡頓 |
| 不留「站著不動」空檔 | AI 自行加戲、演出多餘甚至犯規動作 |
| 影片不要求清楚可讀文字 | 跨影格文字不一致 |
| 不生撲克牌 / 骰子點數特寫 | 精細花色必然扭曲 |
| 距離感要給視覺線索、不能只寫數字 | AI 不理解抽象距離 |
| 檢查鏡頭視角邏輯（自拍看不到手機本身） | 自相矛盾的描述 → 畫面崩 |
| 舞蹈避免手臂交叉過身體 | 低解析下手部崩壞 |

> **寫任何 prompt 前先問：「這句話，AI 有沒有能力做對？」** 做不對的，換一種寫法達成同樣效果，
> 而不是寫上去賭。

## Part A — 爆款雷達：靈感從哪裡來（Sourcing Radar）

repo 從不「憑空發想」。四條固定的取材管道，優先序由上而下：

| # | 管道 | 具體來源 | 抓什麼 | 出處 |

| 4 | **參考帳號原型** | `@sophieraiin` / `@corinnakopf` / `@thenewclassic` / `@miakhalifa` / `@11.mzzz` | 風格原型（archetype），**非身分** | `style-guideline.md` §6、`flavors.md` |

### A.1 三條硬性紀律

1. **熱曲會過期 —— 發片前重抓。** 選曲不是企劃階段就定案的事，`05` §C.b 明文要求「發片前重抓當週榜」。
2. **絕不為了蹭而硬套。** 沒有真的契合的時事，就回到原本的發想方式。
   > 「牽強感會比沒有時事更糟。」——`content-production-rules.md`
3. **參考帳號只取風格，不取身分。** 一律建立**原創身分、臉孔與姓名**，不複製任何真實個人的長相、
   身分或私人生活（`03` 開頭警語、`flavors.md` Flavor 3 註記、`brooke-sinclair/character.md:216`）。

## Part B — 爆款拆解法：七欄配方（Teardown Template）

找到標竿素材後，用固定七欄拆解，拆完直接變成可生成的配方。這是 `05` §F.4 的做法，可通用於任何參考片。

| 欄位 | 要填什麼 | 判斷重點 |
|------|---------|---------|
| **規格** | 解析度 / fps / 長度 / 有無音樂 | 高於自研的，可直接當動作驅動素材 |
| **記憶點** | 那個「可被模仿、可 meme」的招牌動作或瞬間 | 找不到記憶點 = 這支不值得取材 |
| **段落** | 亮相 → 主歌 groove → 副歌 hook → 收尾 | 有無明確的「起承轉合」 |
| **服裝** | 上衣 + 下身 + 鞋 + 配件，當一整套 styling 看 | 是「時裝級」還是「近內衣」 |
| **場景 / 打光** | 對應 `04` §2.4 的 L1–L5 打光原型 | 主體是否亮於背景、光有沒有「雕」出形 |
| **選曲** | 曲風、BPM、副歌落點 | 有沒有明確的 drop 給記憶點動作 |
| **尺度 / 適配 KOL** | 走自信剪裁路線還是裸露路線 / 配哪位 KOL 調性 | 尺度錨在「自信 + 剪裁」，不偏裸露 |

**已完成的兩份範例配方**（可直接複製）：BABYMONSTER 夏日女團戶外、DANZZUP STREET JAZZ 教室街舞
——見 `05` §F.4。

### B.1 拆完之後：轉成動作驅動（已驗證有效）

`05` §F.6 的 POC 已驗證的可複製配方：

> **KOL 全身正面圖 + 從取材 Reel 裁出的「單人中央 9:16」驅動片
> → Kling Motion Control（`scene_control=image` 保 KOL 場景 / `video` 借教室 spotlight）
> → 720p 輸出 → face-restore 補臉。**

這條路一次補上「舞步線條」與「解析度」兩塊短板，是目前縮小與外部工具差距**最有效的單一手段**。

> ⚠️ 取材素材僅供內部方法驗證 / 動作參考驅動 / storyboard，**不得二次發佈**（見
> `kols/sofia-vargas/videos/README-dance-demos.md` 的使用限制）。正式發佈需換無浮水印驅動 + 可商用配樂。

## Part C — 五大爆款母公式（Master Formulas）

11 位 KOL 的 `content_style.md` 各自寫了 4–6 條「爆款內容公式」，往上抽只有 **五條母公式**。
新角色設計公式時，從這五條各挑一個角色化的變體即可。

### C.1 母公式一：反差（Contrast）★ 最高頻、最核心

**機制：** 視覺負責吸睛，文字負責降距離。**反差 = 親和力 = 留言動力。**

| KOL | 變體 | 反差軸 |
|-----|------|--------|
| Chloe Lin | 「反差感」 | 性感照 × 日常狼狽文 |
| Mika Tran | 「Aesthetic vs Reality」 | 辣照 × 超廢誠實配文 |
| Brooke Sinclair | 「美照 + 神經 caption」 | 精修 glam 照 × 完全不相關的怪念頭 |
| Sienna Lai | 「Aesthetic vs Reality」 | 成果照 × 誠實幕後翻車 |
| Sofia Vargas | 「我不是你以為的那種女生」 | 美食／時尚形象 × gaming setup |
| Jax Calloway | 「隨便一張都很好看」 | 有魅力抓拍 × 隨性自嘲配文 |
| 謝宜蓁 | 「以前 vs. 現在」 | 同一地點，生子前後 |

**設計層的反差**（不只是貼文層）：
- 純欲風 = 清純臉 × 線條身材（`style-guideline.md` §1「反差萌」視覺法）
- 智性數字人 = 出身博弈鄰接平台 × 只談規則與設計（`flavors.md` Flavor 5）
- 場景反差 = **「衝突感場景」是流量密碼**（`04` §2.5：精緻美女 × 印度鄉村茅草屋）

### C.2 母公式二：低門檻互動（Low-Friction Engagement）

**機制：** 把留言成本壓到最低。

- 「A 還是 B？」二選一投票——**留言門檻最低、互動率最高**（`style-guideline.md` §4、`chloe-lin`）
- 開放式收尾問句：貼文結尾幾乎一定丟一個開放式問句（`style-guideline.md` §2）
- 但問句要像**隨口問一句**，不是「留給觀眾深刻反思」那種刻意收束（`content-production-rules.md`）

### C.3 母公式三：視角上翻（Reframe / One Level Up）

**機制：** 不回答大家都在回答的問題，把問題往上翻一級。這同時是**差異化**與**合規安全區**。

| KOL | 變體 |
|-----|------|
| Faye Tan | 「別人拍 X，我拍 Y」——別人拍賭場大廳，她拍天花板與藝術品 |
| Tan XiaoXiao | 「規則 → 而非結果」——不問「為什麼有人贏」，問「為什麼規則允許這種結果」 |
| Loi Ma Cheung | 「為什麼它讓你有感覺？」——不評價好壞，拆體驗設計 |
| Faye Tan | 「一個問題 → 一座城市」——用戶記住的是一個觀點，不是一張照片 |

> **這條母公式的雙重價值**：既拿到差異化，又天然避開合規紅線。三位 showgame.live 角色的
> 全部內容都建立在此（見 `docs/showgame-live-weekly-content-sample.md`）。

### C.4 母公式四：真實破綻（Deliberate Imperfection）

**機制：** 完美的相反才顯得真實——**刻意的不完美**。

| KOL | 變體 |
|-----|------|
| Sofia / Brooke | 「跟我一起失敗 / 擺爛」——記錄做壞的料理、輸掉 ranked、GRWM 翻車 |
| Mika Tran | 「放上廢片」——photo dump 裡故意混進不好看的 frame |
| Sienna Lai | 「誠實的攻略」——附上真實花費、缺點、踩雷 |
| Tan XiaoXiao | 「先承認不知道」——「我不知道，但我會去讀」 |
| Loi Ma Cheung | 「現場實驗」——允許失敗、允許不知道 |

> **態度是關鍵**：是「笑著繼續」／「面癱式自嘲」，**不是崩潰**。真實感 = 留存率；
> 誠實比正確更能建立長期信任。

### C.5 母公式五：可累積系列（Serialized Memory Anchor）

**機制：** 單篇爆款是運氣，系列才是資產。**形成長期 IP 記憶點。**

- 香香：「今晚這支」/「有個客人⋯⋯」/「喝酒要懂」/「今晚的場子」/「慢下來」五個固定系列，
  每個系列都有**固定格式**（場合 → 感受 → 適合誰）
- 謝宜蓁：「第一次」/「閨蜜來了」/「帶著小葉去」，每個都寫明格式與視覺重點
- Tan XiaoXiao：「一頁書 → 一個觀點」，每天一分鐘、一本書、一頁內容
- Jax Calloway：「三種場域輪替」（festival / road-trip / streetwear），避免單一場景疲乏，
  同一套造型母題在三種光線下都要成立

> **對應到視覺層**：重複道具強化識別度（Brooke 的 iced coffee、Jax 的腰帶與疊戴項鍊）——
> `03` §造型母題明文稱之為「品牌內品牌錨點」。

## Part C.6 — Hook 結構（前 5 秒）

短影片的固定三段結構（`docs/showgame-live-weekly-content-sample.md` 全部短影片腳本均採此格式）：

```
鉤子（0–5s）→ 主體（5–45s）→ 收尾（45–60s）
```

**鉤子的寫法：一句反直覺的問句。**
- 「連續開出三次一樣的結果，第四次會不會改變？」
- 「為什麼很多賭場，都沒有窗戶？」
- 「為什麼一個聲音，可以讓你記住一個角色十年？」

**舞蹈片的對應**：短版 5–8s 專門用於鉤子，長版 15s 用於完整一段（`04` §2.1）。
**自我介紹片的對應**：Sofia 自介的核心記憶點放在 0:36–0:50 的「反差揭露」，
且 reveal 鏡頭用 **0.8x 慢速加強懸念**、deadpan 鏡頭**刻意停留久一點不要急著切**
（`kols/sofia-vargas/edit_timeline_self_intro.md`）。

## Part D — 四維判準（Four-Axis Judgment Rubric）★ 本文件核心

發片前逐軸自評 1–5 分，低於門檻要重做。

| 軸 | 1（不及格） | 3（可用） | 5（理想） | 門檻 |
|----|-----------|----------|----------|------|
| **娛樂性 Entertaining** | 呆板展示，看完沒有任何記憶 | 有節奏、有內容 | **有記憶點、想重看、想模仿** | ≥4 |
| **音樂性 Musicality** | 無音樂或音樂與畫面無關 | 有配樂、大致合拍 | 選當週熱曲、動作 hit 精準落在重拍、副歌落點對上記憶點 | ≥4 |
| **真實性 Authenticity** | 廣告棚拍感 / 磨皮塑膠感 / 擺拍等待鏡頭 | 自然光、有生活感 | 像「剛好被拍到」的真實瞬間，保留毛孔與小瑕疵 | ≥4 |
| **動作流暢性 Motion Fluency** | 一格一格卡頓、手部崩壞、殘影 | 動作連貫、無明顯崩壞 | 線條俐落延展、卡點乾淨、首尾可無縫循環 | ≥4 |

> **一票否決（沿用 `05` Part D）**：優雅軸 ≤2（判定低俗）→ 直接重做，不論其他軸多高。
> 本文件四軸再加一條：**動作流暢性 ≤2（明顯崩壞）→ 直接重做**，因為崩壞無法靠後製救。

---

### D.1 娛樂性（Entertaining）— 「想重看、想模仿」

**判準核心：** 娛樂性不等於「動作大」，等於**有沒有一個可以被複製的記憶點**。

#### 檢查清單

- [ ] **有 1 個副歌招牌動作**，落在最好記的段落上，且**可被模仿、可 meme**（`05` §C.a / §F.2）
- [ ] **段落結構完整**：亮相 pose → 主歌 groove（小）→ 副歌 hook（大）→ 收尾 pose
- [ ] **重拍上有 freeze / hit**，製造「切」的爽感與力度
- [ ] **場景有反差或資訊量**——空房間白牆會讓畫面單薄、缺記憶點（`05` §B）
- [ ] **前 5 秒有明確鉤子**（一句反直覺問句／一個懸念畫面）
- [ ] **有近景 cut-in**：每 15s 穿插 1–2 個半身／胸上鏡，讓表情戲進得來（`05` §C.d）

#### 常見扣分與修法

| 症狀 | 根因 | 修法 |
|------|------|------|
| 「有跳，但看完沒印象」 | 全片同一個律動強度，沒有 hook 段落 | 段落化：主歌收小、副歌放大 |
| 「動作很多但很散」 | AI 自主編舞、線條不夠俐落 | 改用真人舞蹈參考驅動（motion transfer） |
| 「畫面單薄」 | 場景資訊量不足 | 換有縱深 / 有反差感的場景 |
| 「表情戲不見了」 | 全身遠景下臉僅 60–90px | 取景收到膝上／腰上 + 加近景 cut-in |

---

### D.2 音樂性（Musicality）— 「卡拍是質感關鍵」

**判準核心：** `04` §2.6 的原話——**先選曲、抓 BPM / 重拍，再讓動作卡點**。順序反了就救不回來。

#### 檢查清單

- [ ] **選曲是當週熱曲**（發片前重抓，不是企劃期定的那首）
- [ ] **BPM 落在 100–130 甜蜜點**，且有明確的 **drop / 副歌**給招牌動作落點
- [ ] **截的是最紅的 15 秒**（最好記的副歌段），與影片長度對齊
- [ ] **動作關鍵幀對齊重拍**（抓 beat grid 對拍）
- [ ] **響度足**：trending-sound 風格 mean 約 −8 ~ −16dB；私密／臥室情境可用較輕柔（約 −27dB）
- [ ] **曲風配人設**：甜／酷／性感依 KOL 調性選，**別硬套**
- [ ] **循環對齊**：音樂段落與影片長度對齊，可無縫 loop
- [ ] **版權**：商用需確認授權或改用可商用曲庫

#### 分軌的音樂性（不只舞蹈片）

| 內容型態 | 音樂性的判準 |
|---------|------------|
| 舞蹈片 | 動作 hit 對齊重拍；靠音樂驅動，不放人聲對白（`04` §2.6） |
| 自我介紹 / 口白片 | 背景音樂壓到 VO 之下（Sofia 自介壓至 −15dB）；快切切點踩在 beat 上（`edit_timeline_self_intro.md`） |
| 靜態貼文 | 柔和夢幻、city-pop / 輕電子；深夜文配抒情慢歌（`style-guideline.md` §5） |

#### 常見扣分與修法

| 症狀 | 根因 | 修法 |
|------|------|------|
| 「有音樂但沒感覺」 | 先做動作再配樂 | 反過來：選曲 → 抓重拍 → 動作卡點 |
| 「熱度沒吃到」 | 用了企劃期選的歌 | 發片前重抓當週榜 |
| 「音樂跟人設違和」 | 硬套熱曲 | 曲風先過人設調性這關 |
| 「卡點對不上長度」 | 未做 tempo-fit | 用 `atempo` 對齊影片長度以維持卡拍（見 Sofia dance demo 配方） |

### D.3 真實性（Authenticity）— 「不是拍得好，是像真的被拍到」

**判準核心：** `02` 的預設視覺語言 **Film Candid** 就是整套真實性標準——
「主角看似剛被拍到」，而非「廣告棚拍感」。

#### 檢查清單：視覺層

- [ ] **無感後製**：自然膚色、**毛孔可見**、微光澤但不磨皮
- [ ] **自然光為主**：溫暖陽光 / 柔和窗光 / 黃金時刻 / 樹影斑駁；避免閃光燈、棚燈
- [ ] **35mm 底片感**：輕微噪點顆粒、暖調、輕微降飽和
- [ ] **禁用詞已排除**：`smooth skin` / `airbrushed` / `perfect skin` / `HDR` / `vibrant colors` / `ultra sharp`
- [ ] **不誇張身材後製**（男性版另加：不誇張肌肉線條、避免健美型）

#### 檢查清單：動作層 —— 核心原則「有在做一件事」

`02` §生活化動作準則的判斷方式，是一張**好／壞動作對照表**：

| ✅ 好的動作（生活化） | ❌ 避免的描述（廣告感） |
|---------------------|----------------------|
| 撩濕髮往後撥 | `posing for camera` |
| 拿 iced coffee 走路中回頭 | `professional model pose` |
| 靠欄杆看遠處 | `smiling at camera`（改 `soft smile` / `subtle smirk`） |
| 整理比基尼肩帶 | `standing straight looking forward` |
| 低頭滑手機 | `symmetrical pose` / `hands on hips` |

**視線不必對準鏡頭**：`looking slightly off-camera` 最自然，`looking down at phone / coffee` 日常感最強。

#### 檢查清單：拍攝可行性層

- [ ] **一鏡到底可信**：手機手持、不切鏡、不加轉場特效；運鏡可以有，但整支是同一顆鏡頭
- [ ] **時間跨度是人類真的能一次拍完的範圍**（不能一鏡帶過從清晨到深夜）
- [ ] **鏡頭視角邏輯一致**：自拍畫面裡不可能出現手機本身，只有手臂能入鏡到畫面邊緣
- [ ] **距離感有視覺線索**：不只寫數字，要用地面標線、遠處物體變小、可見空地讓距離成立
- [ ] **可加畫面外自然反應音**（尖叫、歡呼、笑聲）——是自然真實的反應音，不是配樂式音效

#### 檢查清單：文案層

- [ ] **日常生活感優先**：隨手記錄的真實感，**不要寫成講道理的教學文，不要格言／詩句式金句結尾**
- [ ] **真人口語**：短句、語助詞（哈、蠻、超、欸）
- [ ] **問句像隨口問一句**，不是刻意收束
- [ ] **簡繁對應角色國籍**：新／馬／中國大陸籍用簡體（xiaoxiao-tan、faye-tan、loima-cheung），
      港／台籍用繁體。此規則同時適用於貼文文案與畫面中的視覺文字

#### 真實性的進階形態：刻意保留不完美

Flavor 3（Real-IP Sexy，`mika-tran`）把真實性推到極致——**Authenticity > perfection**：
真手機自拍、鏡子照、natural grain、**刻意保留小瑕疵**、避開 glossy studio 與「too-AI」的光滑感。
對應到貼文層就是「放上廢片」公式（photo dump 裡故意混進不好看的 frame）。

### D.4 動作流暢性（Motion Fluency）— 「不是動得多，是動得連續」

**判準核心：** 流暢性的最大殺手不是模型能力，而是**腳本寫法**。
`content-production-rules.md` 的第一條動作規則就是為此而立：

> **動作類影片不要寫成逐秒時間軸腳本（【0:00-0:03】這種格式）——這種寫法會讓 AI 生成的動作變得
> 一格一格、卡頓不流暢。**

#### 寫法層（生成前決定成敗）

- [ ] **用連續流暢的敘述文字**描寫動作先後順序，銜接詞用「接著」「緊接著」「這一瞬間」
- [ ] **明確描寫動作是連續一氣呵成、沒有中途停頓**
- [ ] **避免「站著不動」的空檔**——空檔容易讓 AI 自行加戲、演出多餘甚至犯規動作
- [ ] **鏡頭位置、距離、人物佔比寫清楚**：角度／高度、距離（寫出公尺數）、畫面中的位置與佔比、
      運鏡路徑如何隨時間變化

#### 動作設計層（降崩壞率）

`04` §2.3 的四條共通動作設計原則：

1. **卡拍點**：動作關鍵幀落在重拍上
2. **循環友善**：首尾姿態相近，可無縫 loop
3. **幅度克制**：不做高難度地板動作，降低 AI 崩壞率
4. **保臉優先**：臉部盡量朝向鏡頭、少遮擋，維持 identity 穩定

加上 `05` §C.a 的線條原則：
- **線條優先**：延伸手臂、繃腳背、拉長頸線
- **避免手臂交叉過身體**（低解析下最容易崩）
- **必要時用真人舞蹈參考驅動取代純文字**，換取乾淨線條

#### 交付檢核層（`04` §5 Dance Video QA）

- [ ] **臉部一致**：全片同一張臉，無跨幀漂移
- [ ] **手部無崩壞**：手勢／甩臂段落手指數量、形狀正常
- [ ] **卡拍**：關鍵動作落在重拍上
- [ ] **循環無縫**：首尾姿態銜接，重播不跳幀
- [ ] **背景穩定**：固定機位下背景無鬼影／扭曲
- [ ] **規格**：9:16、≥30fps、音樂已對齊長度
- [ ] **色調一致**：套 KOL 專屬 LUT，膚色跨鏡不跳色

#### 常見扣分與修法（含技術對照）

| 症狀 | 根因 | 修法 | 技術節 |
|------|------|------|-------|
| 動作一格一格、卡頓 | 寫成逐秒時間軸腳本 | 改連續敘述 + 明講一氣呵成 | `content-production-rules.md` |
| AI 自行加戲、多餘動作 | 腳本留了「站著不動」空檔 | 消除空檔，動作首尾相接 | 同上 |
| 手部崩壞 | 幅度過大 / 手臂交叉過身體 / 解析度不足 | 收幅度 + 改線條 + 提升解析度 | `05` §C.a / §C.0 |
| 快動作轉身時臉糊 1–2 幀 | 動態模糊 | 加 face-restore（GFPGAN / CodeFormer） | `05` §F.6 |
| 動態有殘影 | RIFE 未開 Scene Detection | 開啟 Scene Detection | `01` S9-02 |
| 表情僵硬無生氣 | LivePortrait α 值過低 | 調高 α（建議 0.65–0.80） | `01` S6-03 |
| 跨鏡頭臉部變化大 | LoRA 未建立 / Seed 未固定 | 鎖 soul_id / LoRA + 固定 Seed | `01` S6-01、S6-04 |
| 嘴形對不上聲音 | 對嘴誤差 > 50ms | 重跑對嘴管線（目標 Δt ≤ 30ms） | `01` S8-02/03 |
| 解析度不足 → 看起來不順 | 未跑超解析度 | Real-ESRGAN 放大 + RIFE 補到 60fps | `01` S9-01/02 |

> **注意「流暢性」與「解析度」的耦合**：`05` §B 已證實，低解析度會讓一支動作更好的片
> **看起來反而不順**。判動作流暢性前，先確認解析度已達標，否則會誤判成動作問題。

## 附錄 — 一句話總結

> **找爆款**：從標竿帳號與當週熱榜取材 → 用七欄配方拆成可重組的參數 → 套五大母公式（反差 /
> 低門檻互動 / 視角上翻 / 真實破綻 / 可累積系列）→ 前 5 秒給鉤子。
>
> **判爆款**：**娛樂性**看有沒有可模仿的記憶點；**音樂性**看是不是先選曲再卡點；
> **真實性**看像不像「剛好被拍到」；**動作流暢性**看腳本是不是連續敘述、有沒有留空檔給 AI 加戲。
> 四軸各 ≥4 才發，動作崩壞或低俗一票否決。
