# 羅凱西 / Cathy Luo — 內容製作指南

**專案代號 B04 · 神話沉浸型 · 2026-08-14 建立**

角色設定見 [`character.md`](character.md)，畫面 prompt 見 [`visual_prompts.md`](visual_prompts.md)。
這份只講「一支影片怎麼寫出來」。

**一句話的內容主張**：照原文的字面把它畫出來，跟你以為的樣子完全不一樣。

## 🛑 選題核心（★ 2026-08-26 Vincent 重新定義，這是她的第一順位判準）

> 原話：「我反而覺得出處不一沒關係，因為神話傳說幾乎都有這樣的問題。重點是有沒有能讓觀眾
> **『深入其境，一探究竟，而且是現實生活很難探索或根本無法探索的神祕地方』**」

**她的定位不是「講神話裡有什麼」，是「帶觀眾去一個平常去不了的地方，
看原文或傳說到底把那裡寫成什麼樣」。**

**選題先問一句：這裡有沒有一個「地方」可以帶觀眾進去？**
優先題型：消失的城市、傳說中的島、古書裡的異境、現實很難抵達的洞穴／森林／海域、
地圖上存在但傳說版本與今天完全不同的地方、根本不存在只能靠文本重建的世界。

🛑 **多版本不是退件理由**（08-26 裁示，舊的「來源越單一越優先」已作廢）。
**版本數是查證難度的訊號，不是題目好壞的訊號。**
正確處理：說清楚「這是一種記載／一個版本」，**不把其中一版寫成唯一真相，
也不把不同文本的細節混成新版本**；每支影片仍維持一個主要文本／版本系統。

⚠ **她的題材範圍 08-18 就擴大了**（決策紀錄 D3）：世界傳說神話 ＝ 中國古籍
（山海經／搜神記／博物志／太平廣記，仍是最厚的礦脈）＋ 世界神話 ＋ 各地民間傳說與地方誌。
**《山海經》是礦脈不是限制。** 08-24 有一次因為讀流程檔的舊轉述，把她六則企劃全寫成《山海經》，
整份重寫。**設定值只認這個資料夾裡的檔案。**

⚠ **主體要在第一句出現。** Pontianak 原稿第一句寫字源（`perempuan mati beranak`），
觀眾還不知道在講哪個地方 → 改成「印尼西加里曼丹的首府 Pontianak，和一隻女鬼同名。」
字源留到後面一句帶過。**而且不要靠對照上一支影片（魔神仔）來讓這一支成立。**

## 每支的固定骨架

三段，總長約 40–48 秒。**每段秒數貼合實際講話字數，不要統一套同一個秒數。**

| 段 | 名稱 | 秒數 | 她入鏡嗎 | 內容 |
|---|---|---|---|---|
| 1 | **原文** | 8–10 秒 | 入鏡／邊走邊講 | 讀出原文（Kuntilanak 已改成她邊走邊講到定格舉手，不是書頁＋手的版本，原文字用畫面文字浮現） |
| 2 | **景象** | 16–20 秒 | **開頭入鏡，很快退出畫面，剩生物／異獸單獨特寫** | 照字面長出來的地景／異獸——她只在段落開頭出現幾秒帶入，之後鏡頭完全轉向生物，由遠到近逼近，她不在畫面裡 |
| 3 | **落差與來源** | 12–14 秒 | 入鏡 | 大家以為的樣子是後來的畫法；這條記述可能從哪來，收在邀請留言 |

### 🛑 2026-08-26 訂正：段2「她在畫面裡帶你看」不準確，實際是「她退場、生物單獨特寫」

比對魔神仔（鏡頭5-6：自拍轉POV走向生物→生物zoom in，她不在畫面）與 Kuntilanak
（段2首幀她入鏡半身，但口白一開口就幾乎立刻切到「只剩鬼的畫面」，尾幀「她不入鏡，只有鬼」），
**2支樣本一致：段2不是「她跟生物一起入鏡」，是「她短暫帶入之後完全退出畫面，剩生物特寫」。**

**這是真正確定的結構公式（2/2支驗證，跟精確機位角度是不同層次的東西——
角度/距離每支都刻意換掉，但這個「入鏡→退場→生物特寫→回到入鏡收尾」的順序沒變）：**
① 她入鏡讀原文／開場 → ② 鏡頭轉向生物，她退出畫面，生物單獨特寫、逐漸逼近 →
③ 回到她入鏡，講結論與出處，邀請留言。

### 🛑 2026-08-26 訂正：比對魔神仔、Kuntilanak 兩支實際口白，下面舊寫的三句固定台詞
只有第一句是真的逐字照搬，另外兩句其實是「預設值，內容不符就整句換掉」，
而且片頭那句本身也漏了更前面一拍。**片頭／收尾的正確版本改成廣義的功能描述，見下：**

**片頭（條件式，不是每支都一樣開場）**：
- **有時效性的題材**（節日／上映／時事，例如魔神仔蹭鬼月、Kuntilanak 蹭電影上映）
  → 先一句「為什麼是現在」的時效掛鉤，再接「原文只有這幾個字——」引出原文。
- **沒有時效性的題材**（例如山海經常年素材）→ **直接**用「原文只有這幾個字——」開場，
  不用硬湊一句時效鉤子。
- 「原文只有這幾個字——」這句本身是唯一逐字都照搬的固定句。

段 1→2 的橋，預設是**「來，你看這個。」**，但這只是預設值——內容需要更快的節奏
（例如 Kuntilanak 客戶要求「口白幾乎不等鋪陳就切到鬼本身」）就整句換掉，不是每支都留。

**收尾（廣義＝講出處，不是逐字「書上就是這樣寫的」）**：
真正的樣子是**具名出處句 ＋ 邀請觀眾留言分享類似經驗**：
- 魔神仔：「這是登山客林正義自己講的長相……你要是也遇過什麼奇怪的事，記得留言跟我說。」
- Kuntilanak：「這個習俗在馬來西亞跟印尼流傳到現在……你如果也聽過類似的說法，留言告訴我。」
→ **「留言告訴我／留言跟我說」這句邀請語，兩支幾乎逐字一樣，這才是真正凍結住的東西**，
不是文件原本寫的「書上就是這樣寫的」——那句在口傳（非文獻）題材上會變成編造出處，
Kuntilanak 那支就把它拿掉了。
⚠ **只有 2 支樣本，方向可信但還不到 🟢**，下一支比對到再收斂一次。

### 口白字數預算

🛑 **2026-08-25 更正：這裡原本寫的 `(秒數-1) × 6.3 字/秒` 已作廢**（`CLAUDE.md`「交付格式與分工」
那節明寫「`(秒數-1)×6.3` 與 `字數÷5.4＋1` 都已作廢，不要再用」，這份檔案沒同步改，一直在用錯的公式）。
**現行公式**：秒數 ≈ 字數 ÷ 4.9〜5.0，結尾留約 1 秒無台詞：

- 段 1：9 秒 → **約 44〜45 字**（其中原文本身通常只有 15–25 字，剩下是她的引言）
- 段 2：18 秒 → **約 88〜90 字**
- 段 3：13 秒 → **約 64〜65 字**

**段 1 可以比預算少**——原文讀完停半拍再接橋句，那個空檔是質感。
**段 3 不要低於預算下限**，那是唯一給資訊的地方，講不完就換題目，不要壓縮到聽不懂。

### 收尾那 1 秒（有效的寫法）

每段最後留 1 秒不說話，prompt 要寫：

> 「這幾句講完之後，最後一整秒她完全安靜：嘴巴閉著不再說任何一個字、不再有任何動作，
> 只是看著鏡頭……**不要把話拉到影片最後一幀**。」

只寫「停住一整秒」實測只會得到 0.5 秒；沒特別強調就完全沒有。（林曜四段的對照組驗證過。）

## 段 1 怎麼寫（原文）

**只讀原文＋一句引言，不解釋、不預告答案。**

```
原文只有這幾個字——
「有神焉，其狀如黃囊，赤如丹火，六足四翼，渾敦無面目。」
（停半拍）
來，你看這個。
```

規則：

1. **逐字引用，並在畫面或口白裡交代篇名**（例如《山海經·西山經》）。
2. **原文那幾秒放慢、咬字清楚**——這是全片唯一該慢的地方。其餘一律用通用語速固定寫法。
3. **不要用「相傳」「據說」「古人認為」**。那是把責任推給空氣。她說的是「這一段這樣寫」。
4. **不要在段 1 就講結論。** 落差感靠段 2 的畫面自己打出來，先講破就沒有了。

---

## 段 2 怎麼寫（景象）

**她在畫面裡，帶你看。語氣是導遊，不是說書人。**

寫法：把原文的每一個字**當成畫面指令逐項兌現**。原文說「六足四翼」就要看到六隻腳四隻翅膀；
說「無面目」就真的沒有臉。**觀眾要能一句一句對照回原文**——這就是這個帳號的賣點。

```
你看牠這個樣子。像一個袋子，發紅光，六隻腳、四隻翅膀，
然後——沒有臉。整個前面是平的，沒有眼睛、沒有嘴。
可是書上說牠「識歌舞」。這個東西會跳舞。
```

規則：

1. **一句對一個特徵**，不要一口氣塞完。每句之間留一點空檔給畫面。
2. **她的反應可以有，判斷不可以有。** 可以說「這個很怪」，不可以說「古人真的想像力豐富」。
3. **不要形容成可愛或恐怖。** 好奇與敬畏，不做萌化也不做驚嚇。
4. 生物與她的互動寫法見 `character.md` 的「跟生物互動的做法」那節——**第一階段一律不接觸**。

## 段 3 怎麼寫（落差與來源）

**兩件事，順序固定：先講落差，再講這條記述可能從哪來。**

```
你在網路上看到的那個版本，多半是後來的人補上去的——
明清的刻本開始給牠畫臉、畫成鳥的樣子。原文一個字都沒提。
至於古人到底看到了什麼，有人說是某種鳥、有人說是天象。
他們是真的看到了什麼，還是想像的，我不知道。書上就是這樣寫的。
```

規則：

1. **落差要具體。** 說「後來的畫法不一樣」沒有力氣；說「明清刻本開始給牠畫臉」才有。
2. **來源的推測一律標成推測。** 用「有人說」「一種解釋是」，不要寫成定論。
   這一段是全片唯一可以出現不確定語氣的地方，也必須出現。
3. **不下道德判斷。** 不說古人迷信，也不說他們比現代人厲害。
4. 收尾固定句必須到位。

## 選題流程

1. **先 `git pull`**，讀 `content-production-rules.md` 與 `docs/content-history.md`（排重永遠先於找題）。
2. **先選文本，再挑條目。** 文本範圍見 [`character.md`](character.md)「主要文本」
   （★ 2026-08-18 已擴到世界傳說神話，《山海經》只是其中一個分支）。
   **選文本時先過侵權風險分級**：山海經異獸與各地冷門民間傳說是低風險、優先做；
   希臘／北歐主神與知名怪物是高風險，要先查有沒有廣為人知的商業定型設計。
   然後挑一個條目，判準三條**全部要過**：
   - **原文夠具體**——有可以逐項兌現成畫面的字（形狀、顏色、肢體數量、聲音、行為）。
     只寫「有獸焉，其名曰某」這種沒有描述的條目直接跳過。
   - **落差夠大**——照字面畫出來，跟通行印象明顯不同。這是鉤子的來源。
   - **畫面做得出來**——靜態或慢速的地景與生物。**不要挑需要高速動作或複雜物理的**。
3. 查證原文逐字與篇名（版本要一致，不憑印象轉述）。
4. 查一下這隻在遊戲／動畫裡有沒有廣為人知的設計——**有的話畫面要刻意避開那個造型，
   避不開就換題材**。★ 希臘／北歐主神幾乎一定會撞（Marvel、God of War），這一步不能跳。

順序是我建議的產出順序，理由寫在括號裡。

## 圖文（靜態貼文）的語域

影片是「帶你走進去」，圖文是**同一件事的靜態版**：一張照字面畫出來的圖 ＋ 幾行短句。

- 第一句就要是鉤子，不要暖場。
- 四行以內，碎片化口氣，不要寫成說明文。
- **原文那一句用引號原樣放進文案**，篇名也要有。
- 收尾不一定要問句；心情陳述或「書上就是這樣寫的」都可以。
- 人要不要入鏡視情況決定，不寫死。

## 生成技術

- **Seedance 2.0**，9:16，三段獨立生成，**不用首尾幀接續**（專案 2026-08-12 明令）
- 參考圖固定餵：`images/ref/` 的三張人物參考照 ＋ 服裝參考圖 ＋ 該支的乾淨背景參考圖
- 前置順序不能顛倒：**定裝照 → 從定裝照 i2i 做服裝參考圖與背景參考圖 → 才生第 1 段**
- 道具中途換狀態（例如某支需要她拿東西）就準備兩張背景參考圖，避免生出兩份同一個道具
- 所有參考圖餵進生成前**逐區放大檢查四個邊緣**（抓假文字、藏在角落的人影、穿幫的現代物件）
- 三段掛同一份聲音（`audio_references` ＋ `generate_audio: true`）
- **段 2、段 3 是對嘴段**，字數嚴格照秒數 ≈ 字數÷4.9〜5.0 抓（`(秒數-1)×6.3` 已作廢）——
  嘴型對不上先檢查字數，不是模型的問題
- 每段 prompt 都要各自重申一次：**不加背景音樂、不疊字幕、不出現可辨讀文字**
  ——否定指令對 Seedance 基本無效，但這幾條每段都得寫
- 品牌標誌類的問題用**遮擋或構圖**解決，不要靠否定句（手持物件寫明「握在哪、哪一面朝鏡頭」）
