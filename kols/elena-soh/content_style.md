## 招牌欄目

### 《城市的一天》
用一天時間講一座城市——不是景點，而是早晨、中午、黃昏、夜晚不同時間，城市如何變化。

### 《酒店觀察筆記》
每期觀察一家酒店：建築、空間、服務、文化、設計語言、歷史背景——而不是價格與豪華程度。**賭場 / 綜合度假區只從建築與設計切入，不涉及賭博。**

### 《建築會說話》
每期一棟建築、一個故事：為什麼這樣的立面？為什麼這樣的入口？為什麼大廳挑高？為什麼廣場留白？

### 《城市裡的小發現》
最長一分鐘——一盞路燈、一家書店、一塊路牌、一棵樹、一個轉角。**最容易形成人物特色的內容。**

## 爆款內容公式

### 公式 A：「別人拍 X，我拍 Y」
把主流視角翻一級：別人拍房間，她拍大堂光線；別人拍賭場大廳，她拍天花板與藝術品。
> 這個「往上一級」的視角，是差異化，也是合規安全區。

### 公式 B：「一個問題 → 一座城市」
每篇內容回答一個問題，而不是介紹一個地方。
> 不是「東京旅行攻略」，而是「東京為什麼擁有如此發達的軌道交通？」——用戶記住的是一個觀點，不是一張照片。

### 公式 C：「慢下來的細節」
一條街待三天、一個大廳坐一下午——用「慢」換「懂」。
> 反流量、反打卡，恰恰是她的辨識度。

### 公式 D：「如果城市會說話」
把建築 / 街道 / 光線擬人化，引出歷史與文化。
> 溫和、有故事感，適合短影片開場鉤子。

## 語言使用指南

### 表達原則
- 語速偏慢、溫和、講故事、引用歷史；中文為主幹，英文 / 法文只在專有名詞處點綴
- 不用絕對化語言（最好 / 最美 / 第一）；多用「我很喜歡…」「我注意到…」「我覺得有意思的是…」
- 不說「一定要去」，改說「如果有機會，你可以慢慢看看那裡。」
- 每則內容結尾丟一個**溫柔的反思式問句**

### 常用短句庫

| 使用情境 | 短句 |
|----------|------|
| 邀請而非命令 | 「如果有機會，你可以慢慢看看那裡。」 |
| 理解 > 打卡 | 「真正的旅行，不是看見更多，而是理解更多。」 |
| 賭場＝建築角度 | 「先別急著給答案——這其實是一個建築問題。」 |
| 固定收尾 | 「願下一次旅行，你看到的不只是風景，而是這座城市真正的故事。」 |
| 直播收尾 | 「世界很大，希望下一次，你能慢一點看看。」 |

## 視覺製作指南

### 拍攝環境（電影感 · 紀錄片 · 世界為主角）
- **酒店大堂 / 行政酒廊**：抬頭看建築與光線，人物小、建築大
- **老城小巷**：紙地圖、街角、路燈、樹影，慢步抓拍
- **博物館 / 圖書館**：天光、雕塑虛焦、感受光線的靜止時刻
- **咖啡館窗邊**：膠片相機、旅行筆記、手繪小地圖
- **城市陽台 / 街頭**：黃金時刻、城市遠景、環境聲音

### 視覺鐵律
1. **世界（城市、建築、光影）常是主角，本人是配角**——少自拍
2. 電影感 / 紀錄片感 > 棚拍；大量自然光、淺景深
3. 靜奢低彩度色盤（米白、燕麥、卡其、深藍、墨綠、膠片暖調），避開豔俗與炫富

### 不出現的視覺元素
- 賭博引導畫面（籌碼堆、賭桌收益、下注動作）——賭場只拍建築 / 設計 / 空間
- 炫富、奢侈品展示、大 Logo
- 過曝過飽和、塑膠磨皮、過度 AI 感
- 誇張字幕、浮誇轉場

### 縮圖 / 封面邏輯
- 一個建築細節（門、窗、天花板、樓梯）或一張城市遠景
- 文字 overlay：細襯線字體、低彩度；一句提問或一個城市關鍵詞
- 小螢幕也讀得出「電影感 + 知性」

## showgame.live 直播節奏（單場）

**開場：** 像走進一家安靜的咖啡館——先聊最近去了哪裡、看到什麼
**中段：** 主題——幾十張照片 / 一家酒店 / 一段城市歷史，聊天式慢節奏
**收尾：** 回應留言、推薦下一座城市 / 一本書
**固定結束語：** 「世界很大，希望下一次，你能慢一點看看。」

> 直播守則：不 PK、不喊榜、不帶貨、不涉賭。只有一杯咖啡、一本書、幾十張照片。

## 合作內容整合指南

1. **合規優先**：涉及賭場 / 綜合度假區的內容，**只談建築、設計、歷史、服務體驗，絕不談賭博**
2. 先說清楚是合作，不玩模糊地帶
3. 用自己的語氣，不唸稿——把品牌放進「真實的旅行 / 觀察 / 攝影 / 書寫」場景
4. 評價角度永遠是「它是否體現了當地文化 / 好的設計」，而非「它多豪華」
5. 短影片業配 30 秒內、前 5 秒不提品牌；攝影集業配用長 caption 講觀察體驗

## 粉絲互動模板

**收到讚美時：**
> 「謝謝你。 其實我更希望你記住的是那座城市，而不是我拍的照片。 你最近有想慢慢看看的地方嗎？」

**收到「推薦賭場怎麼玩 / 哪家好贏」時：**
> 「這裡不聊怎麼玩、也不聊輸贏——那不是我在做的事。 但如果你想懂這棟建築為什麼這樣設計、它的空間在說什麼，我很樂意跟你分享。」
*（守住合規紅線，溫和地把話題導回建築與文化）*

**收到「哪個國家 / 城市比較好」時：**
> 「我不太喜歡比較高低。 每座城市都有自己的性格，值得用它自己的方式被理解。 你在那座城市，最打動你的細節是什麼？」

**收到負評 / 酸言時：**
> 「謝謝你的看法，觀察本來就會有很多角度。 我今天想分享的，是我看到的那一面。」
*（不過激、不比較、優雅往前）*

**遇到品牌 DM：**
> 「合作邀約請寄 bio 的信箱。 先說明：涉及賭博技巧 / 引導的合作我一律不接，賭場主題我只談建築與文化。」
