## 短影片四大系列

### 系列一：《規則一分鐘》
固定欄目，每集回答一個問題。
> 為什麼連續出現三次，不代表第四次一定改變？／為什麼概率不會記住過去？／為什麼隨機事件，看起來像規律？

### 系列二：《今天讀到的一頁》
每天一分鐘，一本書、一頁內容、一句思考。**形成長期 IP 記憶點。**

### 系列三：《案例拆解》
每期拆解一個案例——德州撲克為什麼允許棄牌？百家樂為什麼採用這樣的賠付規則？國際象棋為什麼先手優勢有限？**透過規則設計，引出概率與博弈的討論**（不涉及收益方法）。

### 系列四：《一句話思考》
每集只有一句觀點。「真正重要的，不是結果，而是結果為什麼出現。」——短、容易傳播。

## 爆款內容公式

### 公式 A：「規則 → 而非結果」
別人問「為什麼有人贏？」→ 他問「為什麼規則會允許這樣的結果出現？」
> 把焦點從「輸贏」搬到「規則設計」，這是整個 IP 最大的差異化，也是合規安全區。

### 公式 B：「直覺 vs 事實」
先講一個大多數人會答錯的直覺 → 再用機率拆穿它。
> 蒙提霍爾、賭徒謬誤、熱手效應——重點永遠是「為什麼人容易理解錯」。

### 公式 C：「一頁書 → 一個觀點」
一本厚書只抽一頁、一句話 → 留下一個可帶走的思考。
> 用戶離開時記住的是「一個觀點」，而不是「一張照片」。

### 公式 D：「先承認不知道」
遇到沒讀過、沒驗證的問題 → 大方說「我不知道，但我會去讀」。
> 誠實比正確更能建立長期信任，這是他的護城河。

## 語言使用指南

### 表達原則
- 短句、斷行、邏輯清晰；中文為主幹，英文只在術語處點綴（probability / game theory / expected value）
- 不用絕對化語言（最好 / 第一 / 一定）；改用「我注意到…」「我覺得有意思的是…」
- 不用煽動式標題；不製造焦慮
- 每一則內容結尾丟一個**留給對方思考的問句**（不是強迫互動，是邀請思考）

### 常用短句庫

| 使用情境 | 短句 |
|----------|------|
| 拆穿直覺 | 「連續發生，不等於存在規律。」 |
| 談感覺與結論 | 「感覺可以作為起點，但不能作為結論。」 |
| 談規則優先 | 「先看規則，再看結果。」 |
| 誠實邊界 | 「這個我還沒讀夠，先不下結論。」 |
| 固定收尾 | 「今天，你發現規則了嗎？」 |
| 直播收尾 | 「今天討論的是規則，答案，留給大家自己思考。」 |

## 視覺製作指南

### 拍攝環境（安靜 · 極簡 · 可信）
- **書房 / 書桌**：落地窗、乾淨桌面、一本筆記本、一支鋼筆、一杯黑咖啡
- **圖書館 / 書店**：木質書架、高窗漫射光、翻書折角
- **白板 / 草稿紙**：機率樹、流程圖——他的招牌教學畫面
- **酒店行政酒廊 / 機場候機廳**：暖調金色光、Kindle、降噪耳機、長途旅人感
- **咖啡館**：窗邊、精品咖啡、書頁入鏡

### 視覺鐵律
1. 鏡頭主體常是**物件與思考**（書頁、草稿、白板、咖啡、鋼筆），而不是自拍臉
2. 電影感 / 紀錄片感 > 死板棚拍；自然光為主
3. 靜奢低彩度色調（白、藍、灰、木、咖），避開豔俗與炫富元素

### 不出現的視覺元素
- 豪車、現金、奢侈品展示、大 Logo
- 過曝過飽和、塑膠感磨皮、過度 AI 感
- 誇張字幕、浮誇轉場、喊麥式節奏

### 縮圖 / 封面邏輯
- 一個乾淨的靜物（書 + 鋼筆 + 黑咖啡）或一張手繪流程圖
- 文字 overlay：細襯線 / 細黑體，低彩度；一句提問或一個關鍵詞
- 小螢幕也讀得清主體

## showgame.live 直播節奏（單場）

**開場 5 分鐘：** 聊天、分享最近讀了什麼、今天要拆什麼
**中段 40 分鐘：** 主題內容——畫圖、拆案例、講規則背後的數學結構
**收尾 15 分鐘：** 開放問答（先分析規則、再討論結果）、推薦下一本書
**固定結束語：** 「今天討論的是規則，答案，留給大家自己思考。」

> 直播守則：不 PK、不喊榜、不抽獎、不帶貨、不預測、不引導參與。只有一本書、一張紙、一支筆、一個案例。

## 合作內容整合指南

1. **合規優先**：任何涉及博弈的內容，只談規則 / 歷史 / 數學 / 文化，**絕不談收益、勝率、下注**
2. 先說清楚是合作，不玩模糊地帶
3. 用自己的語氣，不唸稿——把產品放進「真實的閱讀 / 書寫 / 咖啡 / 旅行」場景
4. 重點放「我在什麼情境下會用到它」，而非「這產品多厲害」
5. 短影片業配 30 秒內、前 5 秒不提品牌；圖文業配用長 caption 講真實體驗

## 粉絲互動模板

**收到讚美時：**
> 「謝謝。不過我更希望你記住的是那個觀點，而不是我。 你怎麼看這個案例？」
*（把注意力從「人」導回「內容」）*

**收到「幫我算勝率 / 教我怎麼贏」時：**
> 「我不聊勝率，也不聊怎麼贏——那不是這裡在做的事。 但如果你想懂這套規則為什麼這樣設計，我很樂意拆給你看。」
*（守住合規紅線，並溫和地把話題導回規則）*

**收到「我感覺會…」時：**
> 「感覺可以作為起點，但不能作為結論。 我們來看看規則怎麼說？」

**收到負評 / 酸言時：**
> 「歡迎不同觀點。我們討論邏輯，不討論彼此。 你這個說法，能舉一個可驗證的例子嗎？」
*（不過激、不人身攻擊、把討論拉回事實）*

**遇到品牌 DM：**
> 「合作邀約請寄 bio 的信箱。 先說明：涉及博弈收益 / 預測的合作我一律不接。」
