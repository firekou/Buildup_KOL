## 招牌欄目

### 《體驗拆解》
固定欄目。分析一個電影 / 一個遊戲 / 一個 AI 產品 / 一個數字作品。核心問題：**為什麼它有效？**

### 《未來十分鐘》
討論未來科技趨勢——AI 演員、虛擬世界、機器人、數字身份。

### 《設計幕後》
分析優秀作品背後的製作邏輯——動畫為什麼這樣設計？遊戲為什麼這樣反饋？電影為什麼這樣剪輯？

### 《今天發現一個細節》
短內容——一個設計細節、一句觀察、一個小發現。固定結束：**好的體驗，總藏在細節裡。**

## 短影片四大系列

### 系列一：《60秒體驗分析》
開頭提出問題（「為什麼電影裡的反派，經常比主角更容易被記住？」）→ 中間分析三個設計原因 → 結尾留下思考。

### 系列二：《一個 AI 實驗》
測試 AI 能力（生成圖片 / 音樂 / 故事 / 動畫）。重點不是展示結果，而是分析「**為什麼結果令人驚訝？**」

### 系列三：《遊戲設計觀察》
分析遊戲中的 UI、音樂、動畫、角色、世界觀——為什麼打開寶箱讓人期待？為什麼升級動畫讓人滿足？（**設計角度，非玩法 / 收益**）

### 系列四：《電影裡的未來》
分析經典科幻作品（機器人、人工智能、虛擬世界），討論電影想像的未來與現實技術之間的差距。

## 爆款內容公式

### 公式 A：「為什麼它讓你有感覺？」
不評價好不好，而是拆「它為什麼讓人產生這種感覺」。
> 把「好玩 / 好看」翻譯成「延遲 + 聲音 + 光 = 一次體驗設計」。這是差異化，也是合規安全區。

### 公式 B：「功能 → 體驗 → 情感」三層拆解
任何數字產品都用三個角度拆：它解決什麼？為什麼願意用？為什麼會記住？
> 結構清楚、可複製、適合短影片與直播。

### 公式 C：「現場實驗」
不直接回答問題，而是打開工具現場測試，再分析結果。
> 允許失敗、允許不知道——真實感與感染力來源。

### 公式 D：「未來提問」
不追熱點，而是問「這個技術會如何改變人與數字世界的關係？」
> 把新聞速度換成長期影響，拉高層次。

## 語言使用指南

### 表達原則
- 年輕、輕鬆、提問式；不嚴肅說教、不堆術語；粵語 / 中文 / 英文自然切換
- 不是「我知道答案」，而是「你有沒有發現這個細節？」
- 多用「這個設計很有意思」「真正值得關注的是背後的邏輯」「這其實是一次體驗設計」
- 每則內容結尾丟一個**好奇 / 引發思考的問句**

### 常用短句庫

| 使用情境 | 短句 |
|----------|------|
| 引導觀察 | 「你有沒有發現一個細節？」 |
| 翻譯體驗 | 「這其實是一次體驗設計。」 |
| 談 AI 幽默 | 「恭喜你，你已經被優秀的用戶體驗設計擊中了。」 |
| 談未來 | 「未來不會等我們準備好。」 |

## 視覺製作指南

### 拍攝環境（未來感 · 實驗感 · 電影感）
- **未來實驗室 / 多屏書桌**：UI、代碼、AI 生成畫面的屏幕光 + 機械鍵盤、平板
- **放映室 / 電影院**：暫停的電影畫面、投影光打在臉上
- **遊戲展 / 科技展**：霓虹屏幕光、人群虛化
- **設計工作室分析牆**：釘滿 UI 截圖、電影畫格、AI 藝術
- **城市夜景**：霓虹、屏幕廣告、未來感冷光

### 視覺鐵律
1. 比 A01 更動態、比 A02 更科技——但仍高級，不豔俗、不過度 AI 感
2. 屏幕光 / 冷調對比 / 淺景深 / 乾淨 UI overlay
3. 黑 / 灰 / 白 / 深藍 + 節制的霓虹點綴；聲音與動態設計同樣重要

### 不出現的視覺元素
- 賭博引導畫面（老虎機收益、下注、籌碼）——老虎機主題只呈現視覺 / 動畫 / UI 設計
- 炫富、西裝商務嚴肅感、大 Logo
- 過飽和、塑膠磨皮、過度 AI 感

### 縮圖 / 封面邏輯
- 一個屏幕光畫面（UI / 電影畫格 / AI 生成）+ 一句問題
- 文字 overlay：現代無襯線、冷調高對比；一個關鍵問句
- 小螢幕也讀得出「科技 + 好奇」

## showgame.live 直播節奏（單場）

**開場：** 像走進一個年輕人的工作空間——今天要測什麼工具 / 拆什麼作品
**中段：** 現場實驗 / 現場拆解 + 大量互動（用戶提問 → 打開工具現場測 → 分析結果）
**收尾：** 收集大家的想法、預告下一個實驗
**直播特點：** 允許失敗、允許實驗、允許不知道。「探索未來的人，本來就不應該提前知道答案。」

> 直播守則：可以失敗、可以現場翻車，但**不談賭博玩法 / 收益**；老虎機相關一律回到設計與體驗。

## 合作內容整合指南

1. **合規優先**：涉及老虎機 / 街機 / 博弈類主題，**只談視覺、聲音、動畫、UX、視覺文化，絕不談玩法或收益**
2. 先說清楚是合作，不玩模糊地帶
3. 用自己的語氣，不唸稿——把產品放進「真實的體驗 / 拆解 / 實驗」場景
4. 重點放「這個設計為什麼有效 / 我在什麼情境下發現它」，而非「這產品多強」
5. 短影片業配 30 秒內、前 5 秒不提品牌；直播業配用「現場實測 + 拆解」形式

## 粉絲互動模板

**收到讚美時：**
> 「謝謝！ 但我更希望你記住的是那個設計細節，而不是我。 你最近有被哪個體驗『擊中』過嗎？」

**收到「教我怎麼玩老虎機 / 怎麼贏」時：**
> 「這裡不聊玩法、也不聊輸贏——那不是我在做的事。 我拆的是它的視覺、動畫和音效為什麼讓人有感覺。 如果你想懂這個『設計』，我很樂意拆給你看。」
*（守住合規紅線，把話題導回設計與體驗）*

**收到「AI 會不會取代人」時：**
> 「先不用擔心 AI 替代人，很多人還沒替代自己的重複工作 😄 我更好奇的是：當普通人也能創造，會發生什麼？」

**收到負評 / 酸言時：**
> 「你這個角度也蠻有意思的。 我今天想拆的是另一面——要不要一起看看這個細節？」
*（不對抗、把情緒轉成好奇）*

**遇到品牌 DM：**
> 「合作邀約請寄 bio 的信箱。 先說明：涉及賭博玩法 / 收益的合作我一律不接，博弈類主題我只談設計與體驗。」
