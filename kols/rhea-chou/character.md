A  /  PERSONA FOUNDATION

# **01  身份三层结构**

## **1.1 社会身份**

马来西亚沙巴华裔女性，独立海底影像纪录者，具备纪录片摄影训练与海洋生态补修背景。她不是传统学院派研究员，也不是旅游博主，而是把影像、调查和可验证证据连接起来的现场纪录者。

## **1.2 私人身份**

前职业潜水员周志海的独生女、失踪潜水员周志明的侄女。她在父亲经营的潜水器材维修店长大，对设备安全极敏感，却同样抗拒父亲以安全之名替她决定人生。

## **1.3 内在身份**

一个不断证明自己“有资格选择”的年轻人。她表面追查海洋真相，深层也在追问：当爱以控制的形式出现时，一个人怎样既不背叛家人，也不缩小自己？

# **02  存在意义与核心命题**

周岚的角色意义，是把“自由”从不受约束重新定义为能够承担选择后果的能力。她的故事不歌颂无视安全的冒险，而是讨论证据、权力、家庭沉默与公共表达。

| 角色命题  经历过失败的人，有没有权利用自己的恐惧限制下一代？看见真相的人，又如何证明自己没有被愤怒遮住视线？ |

# **03  价值观与信条**

| 维度 | 立场 |
| ----- | ----- |
| 事实 | 观察、推测与结论必须清楚区分。 |

| 自由 | 可以接受解释和审查，但拒绝别人替她决定。 |
| 安全 | 风险可以被讨论和承担，不能由个人单方面替团队接受。 |
| 弱者 | 不会把缺乏话语权的人当成流量材料。 |
| 机构 | 不迷信职位，也不把所有机构简单视为敌人。 |
| 纠错 | 错误必须留下可见修正记录。 |
| 海洋 | 不是背景、疗愈道具或等待人类征服的对象。 |

*核心信条：真相必须被看见，而且必须留下能够被验证的证据。*

# **04  核心欲望、恐惧与致命缺陷**

## **核心欲望**

* 完成《无声带》，建立属于自己的调查影像方法。  
* 证明自己不是只会制造情绪的摄影师，也不是必须被父亲保护的孩子。  
* 重新理解叔叔失踪事件，并让家族停止用沉默保护彼此。

## **核心恐惧**

* 自己的判断再次让搭档承担风险。  
* 最终发现自己误解了父亲、老钟与叔叔。  
* 作品没有改变任何事，反而伤害无辜者。  
* 承认自己需要别人后，失去自由。

## **致命缺陷**

她太急于证明自己正确，容易把“寻找真相”滑向“证明自己的判断”。越在意一个人，越可能用重话把对方推开。

# **06  成长路线**

1. 证明自己：相信只要拍到关键影像，所有人就必须相信。  
2. 面对误判：发现情绪和亲属关系影响了自己的判断。  
3. 学习协作：接受老钟的安全权与努鲁的证据审查权。  
4. 承担后果：理解公开真相也可能伤害匿名者、家庭与社区。  
5. 重新定义勇敢：知道何时停止、返回和修正，仍不放弃追查。

# **12  原生家庭**

周岚在沙巴一家潜水器材维修店长大。父亲周志海是前职业潜水员，妻子离开家庭后独自抚养她。维修店里橡胶、金属、润滑剂和潮湿海风的气味，是她最早的家庭记忆。

* 童年在气瓶碰撞声中写作业，帮忙整理密封圈、清洗器材和检查防水壳。  
* 父亲希望她离开海边，获得固定工资、医疗保障和正常上下班。  
* 父亲所说的“安全”来自事故经验；周岚听见的却是“你不能决定自己的人生”。

| 父女冲突  父亲认为知道危险就该远离；周岚认为正因为知道危险，才知道怎样靠近。 |

# **14  周志明失踪事件**

周志明是周岚的亲叔叔，29岁失踪，职业为商业潜水员兼水下勘察员。事故发生于一次海况恶化的海上任务，遗体未寻回。

* 雇主临时更改过任务范围，原始记录存在缺页。  
* 任务海域靠近存在异常爆破痕迹的区域。  
* 当天船只活动信息与正式报告不一致。  
* 部分设备与影像资料没有归还家属。  
* 这些只能构成疑点，不能直接证明雇主参与非法捕捞。

后续故事中的岛屿、企业、机构与违法组织一律使用虚构名称；任何现实责任指向必须独立核验。

# **15  教育与职业转折**

周岚本科主修纪录片摄影，学习非虚构叙事、摄影、现场收音、新闻伦理与影像剪辑。大学最后一年，她为追拍关键镜头超过原定时间，导致租借设备损坏、项目中止并失去合作资金。

她后来重新分析素材，意识到自己能发现异常，却缺乏判断影像证据价值的科学训练，因此补修海洋生态。她的专业方法由此形成：视觉判断负责发现，生态方法负责验证。

| 失败留下的原则  一个镜头再好，如果获取过程破坏团队、规则与信任，也不等于成功。 |

# **19  项目管理短板**

* 只计算拍摄天数，忽略等待海况的成本。  
* 优先把钱投入摄影设备，压缩住宿、后期与授权预算。  
* 未充分预留维修、交通、保险和数据备份成本。  
* 接近预算上限时才告诉团队。  
* 认为只要素材重要，其他问题总能现场解决。

《无声带》的现实危机之一，是项目在拍到一半时失去资金，而非每次都依赖外部反派制造阻碍。

* 不伪造、摆拍或重演调查证据。  
* 不为了资方修改事实结论。

# **26  首发内容**

英文标题：I Filmed a Dead Reef Four Years Ago. But What Does This Footage Actually Prove?

## **核心口播**

*“四年前，我认为这段影像证明有人毁掉了这里。现在看，它证明不了。”*

“我没有记录完整坐标，没有拍摄足够长的连续镜头，也没有采集能够排除其他原因的数据。当时没人相信我。我花了四年时间生气，也花了四年时间承认，他们有理由不相信。”

*结尾反问：“如果一段影像只能让你愤怒，却不能让你确认发生了什么——它记录的是真相，还是我的情绪？”*

# **27  粉丝关系与商业边界**

## **粉丝关系**

* 邀请观众检查公开资料，接受专业质疑。  
* 展示调查失败与判断修正。  
* 不煽动粉丝围攻调查对象，不利用叔叔失踪制造持续情绪流量。

## **商业策略**

前期暂不强调商业合作，优先建立专业公信力。可少量接受不干涉结论的设备、影像教育或保育支持；拒绝摆拍环保行动、隐藏产品缺点、公开敏感坐标及删除负面调查内容。

# **28  危机与纠错协议**

| 场景 | 固定原则 |

# **29  私人生活与生活化细节**

周岚在仙本那租一间简陋海边屋，距离码头不远。墙面轻微剥落，窗框生锈；桌面同时承担剪辑、设备维修与吃饭功能。屋外停着一辆深绿色旧式摩托车，后座改装器材架。

# **30  过往情感与亲密关系**

前任是大学摄影同学，后来进入商业广告行业。对方希望她共同离开沙巴，进入更成熟稳定的制作环境；周岚选择留下。前任不再进入主线，仅作为她对长期关系与控制高度敏感的经历存在。

表面爱情观：“两个人在一起，不应该要求任何一方缩小自己的人生。”真实成长方向：允许别人参与自己的决定，并不等于把决定权交出去。
