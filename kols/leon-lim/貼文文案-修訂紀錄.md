# 林曜 貼文文案修訂紀錄

記錄每一篇貼文文案**被退了幾輪、客戶每一輪說了什麼、我改了什麼**。
定案版只是結果；**真正有用的是中間那些「為什麼不行」。**

# 🛑 先讀這一段：這份檔案怎麼用，以及怎麼用壞

**客戶 2026-08-19 的原話：「在未來發新影片、要寫貼文的時候，你不要過度參考，這會產生過擬合。」**

## 用法

- ✅ **寫完初稿之後**拿來對照：「我這篇有沒有犯過下面任何一種錯？」
- ❌ **不要在寫之前**拿來當範本填空。
- ❌ **不要把定案版的句型抄過來**（「我覺得有意思的是⋯」「照這些字復原出來，它可能長這樣」
  這種句子在原篇很好，抄到第四篇就是複製人）。

## 為什麼會過擬合——這件事已經發生過一次

`圖文/2026-08-14/2026-08-14.md` 裡寫著一行：

> **三段骨架（2026-08-14 客戶指定，之後的圖文照這個走）**：出處 → 考證到哪一步 → 收在「照記載復原，它可能長這樣」

那個骨架對宙斯那篇是對的。**但 2026-08-19 龐貝那篇，客戶給的結構完全不同**——
時間地點 → 為什麼史無前例 → 所以留下別人沒有的東西 → 因為同時具備哪些條件 → 少一項就沒有。

**所以「之後的圖文照這個走」這句話是錯的**，那是一種可用的骨架，不是唯一的。
結構本來就該隨題材變：宙斯那篇的核心是「東西沒了、只剩文字」，龐貝那篇的核心是
「條件很難全部對上」——同一個骨架裝不下兩件事。

★ **判準：三篇裡有兩篇是客戶當場指定結構的。那代表結構是題材決定的，不是人設決定的。**
所以**不要從這三篇歸納出「林曜的文案長這樣」**，只能歸納出「哪些寫法他退過」。

**這篇教到的四件事**
1. 🛑 **被要求補一個點時，只補那個點。** v4 我把「查數據」當成「可以重寫」，一次多加了
   三樣東西，客戶要求整個退回。**查證的收穫不等於文案的授權。**
2. **「特殊性」要落在機制上，不是形容詞。** 「這個地方很特別」沒有資訊；
   「條件很窄，少一項就只會挖到骨頭」才有。
3. **不要用另一個地方當對比**（v2 被退）。客戶要的是龐貝自己為什麼成立，
   不是龐貝比別人好在哪。
4. **「史無前例」要有可查的證據。** 我沒有寫「全世界唯一」這種全稱句
   （上週就有案例因為下了抓不滿的全稱斷言被打掉），改成
   「火山學裡『普林尼式噴發』這個詞就是用他的名字命名的」——這個詞今天還在用，是活的證據。

# 跨三篇唯一真的重複出現的（其他都是題材決定的）

**只有這三條在三篇裡都成立，可以當一般規則；上面各篇的結構與句型都不要跨篇沿用。**

1. **不要重複影片／畫面已經講過的內容。**
2. **語域收緊但要留一句他的立場或好奇**，完全客觀會變論文。
3. **中文語序**：時間地點放句首、長定語拆短句、少用「被」字句。

**還有一個不是規則、但三篇都出現的現象**：
**客戶會直接給結構**（「先講 A，然後 B，因為 C」）。這種時候照他的結構寫，
**不要拿之前哪一篇的骨架去套**——那正是過擬合。
